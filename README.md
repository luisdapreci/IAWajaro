# Exploremos juntos la IA · Fundación Wájaro

Presentación interactiva en formato HTML autocontenido diseñada para una sesión teórica de **55 minutos** con el equipo de la **Fundación Wájaro**. Su propósito es explorar qué ventajas, límites y riesgos podría tener la inteligencia artificial en el trabajo cotidiano, sin dar por hecho su adopción.

## Contenido del repositorio

- [`presentacion-ia-wajaro.html`](./presentacion-ia-wajaro.html): presentación completa en un único archivo HTML (sin dependencias externas ni necesidad de servidor).

## Estructura de la sesión

La presentación cuenta con **20 diapositivas** organizadas en los siguientes bloques:

| Bloque | Diapositivas | Temas principales |
| --- | :---: | --- |
| **Apertura** | 1 – 3 | Bienvenida, ruta de la sesión y punto de partida desde la misión |
| **01 · Entender y cuidar** | 4 – 6 | Qué es la IA y por qué inventa, dónde podría ayudar y semáforo de la información |
| **02 · Pedir y verificar** | 7 – 9 | Receta de un buen encargo, de una petición vaga a una verificable y verificación antes de usar |
| **03 · Escribir y organizar** | 10 – 14 | Voz e imágenes, elegir por tarea, cómo funcionan los *tokens*, planes/suscripciones y chat vs. proyecto vs. asistente |
| **04 · Ampliar con cuidado** | 15 – 18 | Conectores y agentes, flujos con revisión humana, privacidad y tarjeta de cinco preguntas para llevar |
| **Cierre y preguntas** | 19 | Decidir juntos, con criterio |
| **Anexo · Consulta** | 20 | Fuentes de referencia |

## Cómo usar la presentación

1. Descarga o clona este repositorio:
   ```bash
   git clone https://github.com/luisdapreci/IAWajaro.git
   ```
2. Abre [`presentacion-ia-wajaro.html`](./presentacion-ia-wajaro.html) directamente en cualquier navegador web moderno (Chrome, Edge, Firefox o Safari). No requiere instalación ni conexión a internet para visualizarse.

## Funciones y atajos de teclado

La presentación incluye barra de herramientas, notas para facilitar la sesión, índice navegable, soporte adaptable a pantallas pequeñas, exportación a PDF/impresión y respaldo legible si JavaScript está desactivado.

| Tecla | Acción |
| --- | --- |
| `→` / `Av Pág` / `Espacio` | Diapositiva siguiente |
| `←` / `Re Pág` | Diapositiva anterior |
| `Inicio` / `Fin` | Ir a la primera o última diapositiva |
| `I` | Abrir el índice completo de diapositivas |
| `N` | Mostrar u ocultar las notas para facilitar |
| `F` | Activar o salir de pantalla completa |
| `?` | Abrir el diálogo de ayuda |
| `Esc` | Cerrar el diálogo abierto |

También puedes ir directamente a cualquier diapositiva añadiendo su identificador en la URL (por ejemplo, `#s6` para ir a la diapositiva 6) o usar el botón **PDF / imprimir** para guardar la presentación en formato 16:9.
